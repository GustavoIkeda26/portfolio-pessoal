
# Meu Portfólio Pessoal

**Aluno:** Gustavo Proença

## Descrição
Este projeto é meu primeiro portfólio pessoal, desenvolvido durante o curso Técnico em Desenvolvimento de Sistemas da ETEC.

O site apresenta meu perfil, projetos realizados, habilidades e uma seção de contato.

## Tecnologias utilizadas
- HTML
- CSS
- Bootstrap 5

## Funcionamento
O site possui um menu de navegação que permite acessar diferentes seções da página.

Na seção de projetos, apresento alguns trabalhos desenvolvidos durante meus estudos.

## Recurso novo
Adicionei uma seção de habilidades e efeitos de hover nos cartões.

## Como o recurso foi implementado
A seção de habilidades foi criada utilizando HTML e o sistema de colunas do Bootstrap.

Os efeitos de hover foram implementados no arquivo style.css, utilizando propriedades CSS de transição e transformação.
